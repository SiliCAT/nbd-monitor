# nbd-monitor

**NBD Exit Protection & Diagnosis（NBD 退出保护与故障诊断）**

基于 Bash、systemd、Debian nbd-client 和 qemu-nbd 的实验项目。核心目标是防止非正常退出造成旧连接、服务端导出实例或会话长期残留并阻断下一轮连接；在可信证据及安全授权下有限恢复接入能力，无法安全恢复时明确报告并有限失败。本项目不是通用 NBD 设备监控或存储拓扑管理系统。

项目使命、研发准入原则、最小退出证据集 M0 与观察层精简审核见 [PROJECT-SCOPE.md](PROJECT-SCOPE.md)。先论证诊断增益，再决定是否扩展观察业务；新增持久化观察写入与主动处置须另行审核。

## 目录结构

- `server/`：服务端导出、控制请求、超时扫描、退出收尾和可选镜像维护。
- `client/`：客户端会话登记、心跳、退出确认及有限 detach 补做。

两个目录中的 `etc/` 和 `usr/` 与目标 Linux 根文件系统路径对应，可分别部署。配置文件为通用模板，部署前须按实际环境填写；不得覆盖已有实例配置。客户端还需自行维护原生 `/etc/nbdtab`。

## 运行边界

- 单资源单端口、单正式客户端；独立数据通道与控制通道（默认 TCP 10921）。
- 控制协议：previous、register、heartbeat、close。
- 控制通道无身份认证和加密，仅适用于受控可信网络；不要直接暴露到互联网。
- 默认不执行主动超时重置（reset_on_timeout=no）或客户端补做 detach（detach_enabled=no）。
- 仅在上层业务已安全释放设备后停止 NBD；协商完成不代表文件系统一致性。
- 不支持 NBD swap、多管理者抢占或动态自动重连。

## 当前状态

早期实验性源码基线，计划首个正式 Release 为 v0.4.1。保留已验收的 v0.4 双端主程序，并纳入客户端原生连接启动超时 drop-in（30 秒）。新增超时约束需专项实机验收。自动重置、内部快照轮换及临时写入模式尚未完成完整专项实机验收。

当前尚无自动安装器和自动发布工作流。依赖及部署配置需要人工核对；仅在安全停机、无活动数据连接时部署或更新。未声明开源许可证。
